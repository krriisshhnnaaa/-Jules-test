# JavaOOPTeacher

JavaOOPTeacher is a Java Swing-based desktop application designed to teach Object-Oriented Programming (OOP) concepts in an educational and interactive way. It focuses on a practical approach, allowing users to understand core OOP principles such as classes, objects, inheritance, polymorphism, and encapsulation through simulated code execution.

## Features

*   **Interactive Interface:** A user-friendly desktop GUI built with Java Swing.
*   **OOP Concept Lessons:** Modules dedicated to teaching fundamental Object-Oriented Programming concepts.
*   **Simulated Execution:** To prioritize an educational approach, code execution is simulated via string matching and logic evaluation rather than requiring a full backend Java compiler. This allows for focused learning on concepts without the overhead of compilation errors for beginners.

## Prerequisites

To run this application, you will need the following installed on your system:

*   **Java Development Kit (JDK):** A compatible JDK (e.g., JDK 8 or higher). Ensure `javac` and `java` commands are available in your system's PATH.

## Getting Started

### Compilation

You can compile the application from the root directory of the repository using the Java compiler:

```bash
javac JavaOOPTeacher.java
```

### Execution

Once compiled, you can run the application with:

```bash
java JavaOOPTeacher
```

## Structure

*   `JavaOOPTeacher.java`: The main entry point and primary file for the application.
